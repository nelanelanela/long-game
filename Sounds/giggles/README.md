# Giggle sounds

Put the recordings of the laughs here, in any common format (.m4a, .wav, .mp3, .aif, or a voice memo).

- 3 to 6 short laughs work best. Longer recordings are fine too: Claude Code trims each laugh to about 1 second.
- Name them however you like. Claude Code converts and renames them to `giggle-1.m4a`, `giggle-2.m4a` and so on, and copies them into the app's `Resources/Sounds/` folder.
- Keep the originals here. They aren't added to the app as they are.
